Quick start

  1. Serve the folder: npm start (or python3 -m http.server 3000). Opening the files directly from disk also works.
  2. In OBS, add a Browser source pointing at the URL above, sized to match the canvas.
  3. Set the background to Transparent and place your camera source underneath.
  4. Open control.html on a second screen or tablet and drive the lesson live.
  5. To add a lesson, drop a new file in lessons/ and register it in lessons/lessons.bundle.js.
