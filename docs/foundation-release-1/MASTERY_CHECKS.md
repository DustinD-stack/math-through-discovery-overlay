# Foundation Release 1 — Mastery Checks

One mastery check per unit — **8 total**, matching the accepted unit count (P2.15: "8
total unless detailed scope proves a different count is necessary" — detailed
blueprinting confirmed 8 is correct; no unit required splitting or merging).

A mastery check tests more than answer accuracy. Each one below draws on the 8-facet
model from `docs/CURRICULUM_ARCHITECTURE.md` §10 (Recognize, Represent, Break, Build,
Transform, Explain, Check, Transfer), using only the facets that are actually relevant to
that unit — not every facet is forced into every check. Each check is deliberately the
**smallest useful evidence set**, not an exhaustive exam.

---

## MC-0.1 — Foundation Mastery Check I (Quantity Before Symbols)

- **Facets assessed:** Recognize, Represent, Explain, Check.
- **Evidence required:**
  1. Count a group of 7–9 objects correctly, twice, in different orders (Recognize).
  2. Predict, then confirm, that a group's count is unchanged after rearranging it
     (Represent + Explain — "how do you know it's still the same amount?").
  3. Use pairing (not counting) to correctly compare two groups and justify the
     comparison (Check).
- **Pass evidence:** all three tasks completed correctly, with a verbal justification for
  task 2 that references "nothing was added or removed," not just "it looks the same."
- **Reteach trigger:** miscounts the same group twice in different orders (unresolved
  one-to-one correspondence — reteach 0.1.1) *or* believes rearrangement changes the
  count even after a demonstration (reteach 0.1.3 with a longer sequence of examples).
- **What it unlocks:** Unit 0.2.

## MC-0.2 — Foundation Mastery Check II (Parts, Wholes & Number Location)

- **Facets assessed:** Represent, Break, Build, Explain.
- **Evidence required:**
  1. Given a whole (e.g., 8), produce at least two different two-part splits (Break).
  2. Given two parts, state the whole without recounting from 1 (Build).
  3. State that zero is a valid count for an empty group, in a context with no physical
     objects present (Explain).
  4. Place 3–4 given numbers correctly in order along an informal number path and state
     which of two numbers is farther from zero (Represent).
- **Pass evidence:** all four tasks completed correctly; the zero task specifically must
  use the word "zero" as an answer, not "none" or "nothing."
- **Reteach trigger:** produces only one split per whole and cannot find a second when
  prompted (reteach 0.2.2/0.2.4) *or* cannot state zero as a quantity outside a
  removal-demonstration context (reteach 0.2.5 with a non-object example).
- **What it unlocks:** Unit 1.1.

## MC-1.1 — Number Bonds Mastery Check

- **Facets assessed:** Represent, Break, Build, Explain, Transfer.
- **Evidence required:**
  1. Build a bond from a known split (Represent).
  2. Solve a missing-part bond and a missing-whole bond, each for a different whole
     (Break, Build).
  3. Translate a given bond into an equation, and a given equation into a bond
     (Transfer — the PICTURE↔SYMBOL bridge from 1.1.7).
  4. Explain, without prompting, which position in a bond is always the whole ("the
     whole is what the two parts add up to") (Explain).
- **Pass evidence:** all four tasks correct; the missing-part task specifically must not
  show the "add instead of find the difference" error.
- **Reteach trigger:** solves missing-whole bonds but not missing-part bonds (reteach
  1.1.4's difference-vs-sum distinction specifically) *or* cannot translate bond↔equation
  in either direction (reteach 1.1.7).
- **What it unlocks:** Unit 1.2.

## MC-1.2 — Make 5 / Benchmark Mastery Check

- **Facets assessed:** Recognize, Build, Transfer.
- **Evidence required:**
  1. State the complement to 10 for at least 6 of 8 given numbers 1–9, from memory
     (Recognize + Build — direct evidence for Unit 1.3's prerequisite).
  2. Given a number, correctly state whether it's closer to 5 or to 10, with a distance
     justification (Transfer, from 1.2.5).
- **Pass evidence:** both tasks correct at the stated thresholds.
- **Reteach trigger:** cannot state complements to 10 without rebuilding a ten-frame for
  most numbers (reteach 1.2.3–1.2.4 before proceeding to Unit 1.3 — **this is the single
  most important gate in the release**, since Unit 1.3 cannot succeed without it).
- **What it unlocks:** Unit 1.3.

## MC-1.3 — Make 10 Mastery Check

- **Facets assessed:** Recognize, Break, Build, Transform, Explain, Check, Transfer.
- **Evidence required:**
  1. Independently solve a new Make-10 addition problem (not previously drilled),
     narrating each stage (SEE/BREAK/BUILD/TRANSFORM) aloud (Recognize through
     Transform, Explain).
  2. Solve a Make-10 subtraction problem (1.3.4's structure) (Transfer).
  3. Diagnose a shown broken Make-10 attempt and correct it (Check — direct evidence
     from the 1.3.6 Error Analysis lesson).
  4. Correctly decide whether a given problem needs a bridge at all, before solving it
     (from 1.3.5).
- **Pass evidence:** all four tasks correct, with the narration in task 1 including the
  words "same value" or an equivalent phrase when stating the transform step.
- **Reteach trigger:** gets a correct final answer in task 1 but cannot narrate the
  stages (reteach with more think-aloud modeling, not more problems) *or* fails to catch
  the wrong-target-split error in task 3 (reteach 1.3.6).
- **What it unlocks:** Unit 2.1; the release's number-sense strand is now complete.

## MC-2.1 — Place Value Mastery Check

- **Facets assessed:** Represent, Break, Build, Explain, Transfer.
- **Evidence required:**
  1. State the tens and ones for 3 given two-digit numbers (Represent).
  2. Write expanded form for 3 numbers, including at least one with zero ones — **must
     not** produce a `+ 0` term (Break — direct evidence against the flagged
     misconception in 2.1.4).
  3. Compare two two-digit numbers using tens-first reasoning, including one tied-tens
     case (Build).
  4. Produce a regrouped (non-canonical) form of a given number and confirm it's still
     equal (Transfer, from 2.1.3).
- **Pass evidence:** all four tasks correct; task 2's zero-ones case is the specific
  release-blocking checkpoint (see `README.md`'s note on why this matters for D2/D6 in
  later releases).
- **Reteach trigger:** produces `X0 = X0 + 0` in task 2 (reteach 2.1.4 specifically, using
  more zero-ones examples before proceeding) *or* compares by ones-digit-first (reteach
  2.1.5).
- **What it unlocks:** Unit 3.1.

## MC-3.1 — Doubles/Halves Mastery Check

- **Facets assessed:** Recognize, Break, Build, Transform, Transfer.
- **Evidence required:**
  1. State 4 of 5 doubles facts 1–10 from memory (Recognize).
  2. Solve one near-double-plus-one and one near-double-minus-one problem, choosing the
     correct direction for each (Break, Build — direct evidence against the flagged
     3.1.3/3.1.4 confusion).
  3. State half of an even number using its doubles fact, and correctly identify that an
     odd number does not split evenly, naming the leftover (Transform).
  4. Double a two-digit number by doubling tens and ones separately (Transfer).
- **Pass evidence:** all four tasks correct.
- **Reteach trigger:** applies the same near-double direction (+1 or −1) regardless of
  the actual problem (reteach 3.1.3/3.1.4 side by side, contrasting them directly) *or*
  forces an odd number into two "equal" unequal groups without naming a leftover
  (reteach 3.1.6).
- **What it unlocks:** Unit 3.2.

## MC-3.2 — Addition & Subtraction Mastery Check (Foundation Release 1 capstone)

- **Facets assessed:** Recognize, Break, Build, Transform, Explain, Check, Transfer.
- **Evidence required:**
  1. Solve a new compensation-addition problem near a landmark (e.g., a number ending
     in 8 or 9), narrating the give/take pairing explicitly (Recognize through
     Transform, Explain).
  2. Solve a compensation-subtraction problem using the same-direction rule (Transfer,
     distinct from task 1's rule).
  3. Diagnose a shown broken compensation attempt (missing the "take back" step) and
     correct it (Check — direct evidence from 3.2.7).
  4. Given a small-number problem and a landmark-adjacent problem together, correctly
     choose Make 10 for one and compensation for the other, with a stated reason
     (Explain — evidence from 3.2.6).
- **Pass evidence:** all four tasks correct, with task 1's narration explicitly stating
  what was "given" and what was "taken" (not just the final answer).
- **Reteach trigger:** produces a correct answer in task 1 but cannot explain where the
  compensating amount came from (reteach 3.2.7's proof-based framing, not just more
  drill) *or* applies the addition (opposite-direction) rule to the subtraction task
  (reteach 3.2.5 with explicit contrast).
- **What it unlocks:** Foundation Release 2 (D2.2/D2.3, D3.3, D4 — the formal Equivalence
  domain). Passing this check is the release-completion signal referenced in
  `README.md`.
