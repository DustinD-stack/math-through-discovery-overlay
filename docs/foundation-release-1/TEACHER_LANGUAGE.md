# Foundation Release 1 — Teacher & Student Language

Canonical Math Through Discovery language, established here so it stays consistent
across all 57 lesson blueprints in this release and every release after it. This is a
**shared vocabulary, not a rigid script** — teachers and presenters should use their own
words around these anchors, not read them verbatim every time.

## Teacher prompts (canonical, by stage)

| Stage | Canonical prompt(s) |
|---|---|
| **SEE** | "What do you SEE?" · "What do you notice?" · "What are we being asked?" |
| **BREAK** | "What can we BREAK apart?" · "Is there a friendlier number hiding in here?" · "How could we split this up?" |
| **BUILD** | "What are we trying to BUILD?" · "What does that give us?" |
| **TRANSFORM** | "Can we TRANSFORM this into something easier?" · "What stayed the same? What changed?" · "Did the value change?" |
| **CHECK** | "How can we CHECK it?" · "How do you know?" · "Can you show it another way?" |

## Teacher prompts (canonical, cross-cutting)

These apply at any stage and are used throughout the unit blueprints wherever a
misconception or a genuine reasoning moment calls for them, rather than being tied to
one specific stage:

- "What stayed the same?"
- "What changed?"
- "Did the value change, or just the way it's written/shown?"
- "Can you show it another way?"
- "How do you know?"
- "Is there a friendlier number hiding in here?"
- "Did we add or take away anything, or just look at it differently?" (conservation /
  equivalence check — used from Unit 0.1 onward)
- "Would the answer be bigger or smaller than that?" (reasonableness check — used from
  Unit 1.1's missing-part reasoning onward)

**Usage rule:** a prompt is asked *before* revealing whether an answer is right or
wrong, whenever a misconception listed in `MISCONCEPTION_MAP.md` is the likely cause —
the prompt should surface the learner's own reasoning, not simply correct the answer for
them.

## Student explanation sentence frames

Age-flexible frames — support explanation without forcing exact wording. A younger or
less verbal learner may use only the first clause; an older learner rebuilding
fundamentals should be encouraged toward the fuller form.

| Frame | Used most in |
|---|---|
| "I see ___." | SEE stage, any lesson |
| "I broke ___ into ___ and ___." | BREAK stage — Units 0.2, 1.1, 1.3, 2.1 |
| "I did that because ___." | Any stage where a choice was made (e.g., which number to
  split, which benchmark to use) |
| "I built ___." | BUILD stage — Units 1.1, 1.3, 2.1 |
| "I changed the form, but ___ stayed the same." | TRANSFORM stage — the direct verbal
  carrier of Same Value, Different Form; central to Units 0.1.3, 0.2.2, 1.1.6–1.1.7,
  2.1.3–2.1.4, 3.2 |
| "I know my answer makes sense because ___." | CHECK stage, any lesson |
| "I can show the same value as ___." | Any Connection-type lesson (1.1.7, 1.3.5, 2.1.3,
  2.1.6, 3.1.5, 3.2.6) |

**Usage rule:** these frames are offered as scaffolding, especially in early Unit 0.1/0.2
lessons where verbal explanation is itself a developing skill — a correct action
(correct count, correct split) without the sentence frame is still evidence of
understanding and should not be withheld credit for lacking narration, particularly for
younger learners. Full narration becomes an explicit mastery-check expectation starting
at MC-1.3 (Make 10), per that check's evidence requirements.
